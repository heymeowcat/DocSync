

## Overview

The Project Low Level Design Document Generator is a Python-based tool designed to automate the creation and updating of Low-Level Design (LLD) documents for software projects. This tool leverages the `meta-llama/llama-3.2-3b-instruct` to generate detailed LLD sections based on project files and Git commit history.

## Features

 - Automated LLD Creation: Generate a comprehensive LLD document based
   on selected project files. 
 - Git Integration: Update LLD documents by
   comparing Git commits and summarizing changes. 
 - Manual File Selection:
   Manually select files to include in the LLD document through the
   terminal.
